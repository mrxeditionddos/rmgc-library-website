A student-focused academic resource application providing notes, previous year question papers, syllabus information, subjects, events, announcements and educational resources.

📚 About RMGC LIBRARY

RMGC LIBRARY is designed to make academic resources easier for students to access from one place.

The application may provide study notes, PYQs, syllabus, semester and subject resources, college announcements, events, gallery content and educational PDF materials.

🔐 Privacy & Security

We take user privacy and account security seriously. RMGC LIBRARY uses services such as Firebase Authentication, Firestore, Firebase Storage and Firebase Cloud Messaging to provide application functionality.
